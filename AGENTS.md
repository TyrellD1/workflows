# Agent instructions

Read `workflows.md` before creating or editing a workflow.

## Git

- Commit often. Small commits. Message says why, not what.
- Push to the remote at the end of every turn.

## Workflows

- Canonical layout and terms: `workflows.md`.
- Keep SKILL.md, processes, and templates short. Point to files. Do not stuff.
- `SoRs.yaml` and `Taste/` stay placeholders in this repo. Fill them at CONFIG time on a machine.
- Every HiTL template is shown to the human and iterated before a workflow is finalized.
- Every workflow README is human-facing and includes a mermaid diagram.
