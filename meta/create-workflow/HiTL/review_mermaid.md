# Review mermaid

## When

Right after the first mermaid draft. Before scaffold. Chat only.

## Chat

Send the full diagram every round. Do not a2h. Do not write a markdown doc.

````
Create workflow: mermaid for `<name>`

This is the contract. We will not write SKILL.md until you sign off that this matches what you wrote / are thinking.

```mermaid
<full diagram>
```

Reply: sign off / change <node or edge> / redraw from this note: <...>
````

If they ask for a change, update the diagram and send this Chat template again with the new mermaid. Repeat until sign-off.

## Exit

- Continue: explicit sign-off that it matches.
- Keep iterating: any edit. Send the full updated mermaid in chat.
- Give up: user stops the create.
