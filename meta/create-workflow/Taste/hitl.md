# HiTL

HiTL exists to make later loops cheaper. The template is the product.

Black and white:

- Escalation (review or issue): one file with `## a2h` (compressed ping), `## Chat` (working copy), optional `## Doc`. Always log.
- Chat-only only when a process says so (mermaid contract).
- Do not POST to Discord yourself. Use `a2h send --json`.

Guideline: prefer a template over a freeform dump. If you need a new template, write it into that same HiTL file.
