# Create mermaid diagram

Do this right after intake. Do not write SKILL.md yet. The signed diagram is the contract.

Draft one `flowchart TD` from intake plus any hand-drawn flow. If there is no drawing, draft from the purpose and known steps.

Labels:

- Process nodes: `Process <name>` (matches the process file stem)
- HiTL nodes: `HiTL <template>` (matches the HiTL file stem)
- Diamonds: conditions

Keep labels short. No styling.

Then iterate in chat only. Follow HiTL/review_mermaid.md. Send the full updated mermaid each round until the user signs off.

Later, paste the signed diagram into README.md. Do not invent a second diagram.
