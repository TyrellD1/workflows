# HiTL

HiTL exists to make later loops cheaper. The template is the product.

Black and white:

- Every HiTL has a format and exit conditions.
- Every HiTL is logged (`event=hitl`).
- Every new template is shown and iterated before finalize.

Guideline: prefer a template over a freeform dump. If you need a new template, write it, show it, iterate it.
