# Choose bucket

## When

The workflow could live in more than one of `coding/`, `gtm/`, `meta/`, `shared/`.

## Template

```
Create workflow: pick a folder

Name: <name>
Purpose: accepts <X>, ends with <Y>

Options:
- coding/ — software agents
- gtm/ — go to market agents
- meta/ — workflows about workflows
- shared/ — used by more than one workflow

I would put it in `<guess>` because <one reason>.
Confirm or pick another.
```

## Exit

- Continue: one bucket named.
- Keep iterating: still split across buckets. Split into two workflows or pick a home.
- Give up: user stops the create.
