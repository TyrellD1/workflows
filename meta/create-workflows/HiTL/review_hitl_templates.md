# Review HiTL templates

## When

After HiTL drafts exist. Also any time a new template is added. Before finalize.

## Template

```
Create workflow: review HiTL templates for `<name>`

I need you to see and approve each of these before we finalize.

### `<filename>`
When: <when it fires>
Exit: <continue / iterate / give up>

<full template body>

---

Please mark each: approve / change X / drop.
```

Send full bodies. Not summaries. One message is fine if every template is in it.

## Exit

- Continue: every template has an explicit approve (or an edit was applied and re-approved).
- Keep iterating: any template unseen, rejected, or has open edits.
- Give up: user stops the create.
