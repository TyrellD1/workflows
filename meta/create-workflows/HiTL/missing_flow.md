# Missing flow

## When

No hand-drawn flow was given, and the branches in SKILL.md are not obvious from the text.

Skip this if the step list is a straight line and mermaid can be drafted from it.

## Template

```
Create workflow: flow diagram

Name: <name>

<list the condition diamonds>

```

## Exit

- Continue: user provides a sketch, mermaid, or says draft it.
- Keep iterating: user says the branches are wrong but has not replaced them.
- Give up: user stops the create.
