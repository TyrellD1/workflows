# Retrospective

## When

After finalize, once per create run.

## Template

```
Create workflow: retrospective for `<name>`

Path: <bucket>/<name>/

Shipped:
- SKILL.md steps: <n>
- Processes: <list>
- HiTL templates: <list, all approved: yes/no>
- Mermaid approved: yes/no
- README approved: yes/no
- Logger: wrote / skipped because <reason>

What was slow:
- <one or two bullets>

Change in the create-workflows workflow next time:
- <none | specific file to edit>
```

## Exit

- Continue: user replies or ignores. Either is enough to close.
- Keep iterating: user names a change to create-workflows. Apply it or open a follow-up.
- Give up: not used here.
