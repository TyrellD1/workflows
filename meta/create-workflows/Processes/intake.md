# Intake

Collect only what you need to scaffold. Do not design the full workflow in chat.

Get:

- Name (lowercase, hyphens)
- Bucket guess
- One sentence: accepts X, ends with Y
- Trigger: manual, poll, webhook, schedule, other
- Known systems of record (names only; do not fill SoRs.yaml)
- Known HiTL points
- Process names you can already see
- Hand-drawn flow: yes/no, and path or image if yes

If accepts/ends-with is missing, stop and use HiTL/clarify_purpose.md.

Exit: you can write the SKILL.md step list from this intake.
