# Create mermaid diagram

Put one mermaid flowchart in the workflow README. This is how we iterate on diagram taste later.

Rules:

- Boxes = steps. Diamonds = conditions. HiTL nodes labeled `HiTL <template>`.
- Follow a hand-drawn flow if the user gave one.
- If none, draft from the approved SKILL.md step list. Ask via HiTL/missing_flow.md only when the drawing would change branches, not for decoration.
- Show the draft via HiTL/review_mermaid.md. Iterate until approved.

Keep labels short. No styling. `flowchart TD` unless the user asked otherwise.
