# Scaffold

Create:

```
<bucket>/<name>/
  SKILL.md
  CONFIG.md
  README.md
  SoRs.yaml
  HiTL/
  Taste/
  Processes/
```

`name`: lowercase letters, numbers, hyphens. Max 64 chars.

Do not skip folders. Empty dirs get a `.gitkeep` only if they would otherwise have zero files; prefer a real stub from later steps.

If the folder exists, stop and ask. Do not overwrite.
