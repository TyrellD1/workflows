# Create spec

This workflow accepts an idea and ends with INTENT.md, then Design phase.

Log start, each HiTL, and done. Follow Processes/logging.md.

1. Take the idea. Follow Processes/create_round.md.
2. Follow Processes/write_round.md.
3. Escalate using HiTL/ask_questions.md.
4. If the user answers, follow Processes/write_answers.md, then return to Processes/create_round.md.
5. If the user says the plan is clear enough, follow Processes/write_intent.md.
6. Follow Processes/open_intent.md.
7. Done with Plan phase. Next is Design phase.
